# FT-142 · Персональные API-токены + quick-add

**Тип:** Feature · **Оценка:** ~1–2 вечера · **Приоритет:** после rate-limit и handler-тестов

---

## Контекст

Веб-авторизация (JWT в httpOnly cookie + CSRF) работает только для браузера. Для добавления расхода с кнопки «Действие» на iPhone через Shortcuts нужен долгоживущий машинный credential: браузерной сессии на телефоне нет, а JWT протухает за час. Вводим личные API-токены и лёгкий эндпоинт `/quick-add`, принимающий строку `"500 кофе"`.

## Scope

**In:** таблица `api_tokens` (миграция уже в репозитории), генерация/валидация токенов, расширение auth-middleware, CRUD токенов, `POST /quick-add`, страница управления в настройках профиля.

**Out:** rate limiting (отдельный тикет FT-140), категории для quick-add (заглушка «без категории»), синхронная конвертация валют (пишем в базовой).

## Контракт на стыке A↔B

Чтобы части собирались независимо, фиксируем интерфейсы заранее.

**Репозиторий (B реализует, A вызывает):**

```go
type TokenRepository interface {
    Create(ctx context.Context, userID int64, tokenHash []byte, name string) (Token, error)
    GetByHash(ctx context.Context, tokenHash []byte) (Token, error) // только revoked_at IS NULL
    ListByUser(ctx context.Context, userID int64) ([]Token, error)
    Revoke(ctx context.Context, userID, tokenID int64) error
    TouchLastUsed(ctx context.Context, tokenID int64) error
}
```

**Сервис (A реализует, B вызывает из хендлеров):**

```go
// возвращает (plaintextToken, Token, error) — plaintext только здесь и один раз
func (s *TokenService) Generate(ctx, userID int64, name string) (string, Token, error)
func (s *TokenService) Validate(ctx, plaintextToken string) (userID int64, err error)
func (s *TokenService) List(ctx, userID int64) ([]Token, error)
func (s *TokenService) Revoke(ctx, userID, tokenID int64) error
```

**Парсер (A реализует, B вызывает в quick-add хендлере):**

```go
// "500 кофе" -> (500, "кофе"). Чистая функция, без зависимостей.
func ParseQuickAdd(raw string) (amount decimal.Decimal, name string, err error)
```

**Контекст:** middleware кладёт `userID` под существующим ключом. B ничего нового в контекст не добавляет и достаёт `userID` как в текущих хендлерах.

## Требования к реализации (часть A)

- [ ] Токен: `ft_` + 32 байта `crypto/rand`, base64url
- [ ] В базе — **только SHA-256 хеш**, не bcrypt (высокая энтропия → брутфорс невозможен, детерминированный хеш → прямой поиск по UNIQUE-индексу)
- [ ] Plaintext возвращается один раз
- [ ] Middleware **расширяется, не дублируется**: есть `Authorization: Bearer ft_…` → валидация токена; иначе cookie/JWT; иначе 401
- [ ] `last_used_at` через `TouchLastUsed` обновлять не чаще раза в ~10 минут
- [ ] CSRF не применяется к Bearer-запросам — решение по способу аутентификации, не по whitelist путей

## Требования к реализации (часть B)

- [ ] Все три CRUD-эндпоинта токенов доступны **только по cookie/JWT**, не по токену
- [ ] `/quick-add` принимает и токен, и cookie/JWT
- [ ] Парсинг — вызов `ParseQuickAdd` в транспортном слое; сервис получает готовые `amount`, `name`. Новой бизнес-логики в сервисе нет
- [ ] Ошибку парсинга возвращать текстом в теле (Shortcuts покажет в уведомлении)
- [ ] Фронт: список токенов (name, created_at, last_used_at, статус), создание с вводом name, показ plaintext один раз с кнопкой «скопировать», отзыв. Стиль — как в приложении

## Acceptance criteria

- [ ] Создание токена возвращает plaintext ровно один раз; повторно недоступен
- [ ] В `api_tokens` лежит хеш, не plaintext (проверка dump'ом таблицы)
- [ ] `POST /quick-add` с `Authorization: Bearer ft_…` и телом `"500 кофе"` создаёт транзакцию 500 с названием «кофе»
- [ ] Тот же запрос без токена и без cookie → 401
- [ ] Отозванный токен (`revoked_at` проставлен) → 401
- [ ] `POST /tokens` с Bearer-токеном вместо cookie → отказ
- [ ] Существующие браузерные хендлеры работают без изменений (регресса нет)
- [ ] `ParseQuickAdd` покрыт табличным тестом: `"500 кофе"`, `"500,50 кофе с молоком"`, `"500"`, `"кофе"`, `""`
- [ ] Реальный шорткат на iPhone добавляет расход за один диалог ввода
